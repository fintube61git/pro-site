# T Dawson Woodrum professional website

Professional background, research, publications, presentations, and software
by T. Dawson Woodrum, PhD, JD.

- [Professional website](https://www.tdawsonwoodrum.com/)
- [Research CV](https://www.tdawsonwoodrum.com/cv/)
- [Two-page research resume](https://www.tdawsonwoodrum.com/resume/)

The CV and resume are accessible browser pages with built-in print controls.
The CV includes expandable publication and presentation lists.

GitHub Pages serves only the files explicitly listed in `public-files.json`.
The deployment checks the public package before publishing it.
Account records and private maintenance instructions are not part of this
public repository or the deployed website.
